    API reference¶

    Everything below is importable from flask_tenants.

    Context¶

    ::: Primitives for activating a tenant.

    Name Signature Purpose
    tenant_context (tenant) -> ContextManager[Binding] Activate a tenant object. No database lookup, so it works anywhere.
    public_schema (schema="public") -> ContextManager[Binding] Operate on shared tables with no tenant active.
    current_tenant () -> TenantProtocol \| None The active tenant object.
    current_tenant_key () -> Any \| None The active tenant's key. What a worker carries.
    current_schema () -> str \| None The real schema tenant tables resolve to.
    current_binding () -> Binding \| None The full binding, which distinguishes "public" from "unset".
    require_binding () -> Binding As above, raising NoActiveTenantError if unset.
    capture () -> Any \| None The active key, for crossing a process boundary.
    bind / set_binding / reset_binding Lower-level control for adapters whose entry and exit are separate calls. 
    with tenant_context(acme):
    assert current_tenant_key() == acme.tenant_key
    with public_schema():
        assert current_tenant_key() is None     # nesting restores correctly
    assert current_tenant_key() == acme.tenant_key

    Manager¶

    TenantManager¶

    See Configuration for constructor arguments.

    Method Purpose
    tenant_context(tenant_or_key) Activate, by object or key (the key form consults the registry).
    public_schema() Activate the shared schema.
    restore(key) Re-enter a captured context; None restores public.
    resolve(request) Run the resolver chain. Returns a servable tenant or None.
    session() A new session from the configured factory.
    connection(tenant_or_key=None) A Core connection correctly bound, for work outside a Session.

    Models¶

    Name Purpose
    make_bases(registry=None, ...) Build the two bases. Returns Bases.
    SharedBase / TenantBase Prebuilt pair for apps that do not need their own registry.
    TenantMixin slug, schema_name, state, plus assign_schema_name().
    DomainMixin domain, is_primary.
    TenantProtocol The contract: tenant_key, schema_name, state.
    TenantState PENDING, ACTIVE, FAILED, INACTIVE.
    SimpleTenant A tenant with no database behind it. SimpleTenant.for_id("acme").
    validate_model_layout(bases) Assert no shared→tenant foreign keys.

    Registry¶

    Name Purpose
    TenantRegistry Abstract base: get, get_by_domain, all, plus require and active.
    SQLAlchemyRegistry(session_factory, tenant_model, domain_model=None) Reads from your tables.
    StaticRegistry(tenants, domains=None) In-memory, for tests and config-driven estates.

    Resolvers¶

    Name Resolves from
    SubdomainResolver(base_domain, ignore=...) acme.app.example.com
    DomainResolver(registry) The domain table. The default.
    PathPrefixResolver(prefix="t") /t/acme/...
    HeaderResolver(header="X-Tenant-ID") A request header
    SessionResolver(key="tenant_id") session["tenant_id"]
    CallableResolver(fn) A plain function
    ResolverChain(resolvers) First non-None wins

    Provisioning¶

    Name Purpose
    provision_tenant(manager, tenant, runner=None, on_state_change=None) Create the schema and replay migrations. Idempotent.
    deactivate_tenant(tenant, on_state_change=None) Soft delete. Never drops a schema.
    create_schema(connection, name) CREATE SCHEMA with validation.
    ProvisionResult tenant_key, schema_name, created, revision.

    Migrations¶

    Name Purpose
    MigrationRunner(manager, shared_config=, tenant_config=) Drives Alembic.
    .upgrade_shared(revision="head") The shared schema.
    .upgrade_tenant(tenant, revision="head") One tenant.
    .upgrade_all(tenants=None, continue_on_error=False) Every tenant. Returns MigrationRun.
    .status(tenants=None) List of TenantStatus.
    .current_revision(schema_name) Read one schema's version.
    strip_tenant_schema process_revision_directives hook keeping schema= out of autogenerated tenant migrations.

    Operations¶

    Name Purpose
    for_each_tenant(manager, fn, tenants=None, states=(ACTIVE,), continue_on_error=True, max_workers=1) Run once per tenant. Returns BulkResult.
    BulkResult .succeeded, .failed, .skipped, .values(), .all_ok, .summary().

    Workers¶

    Name Purpose
    capture_headers() {"flask_tenants_tenant": key} or {}.
    restore_into(manager, headers) Context manager re-entering that tenant.
    with_tenant(manager, key_arg="tenant_key") Decorator reading the tenant from a keyword argument.
    celery_signal_handlers(manager) Handlers for before_task_publish, task_prerun, task_postrun.
    TENANT_HEADER The header key.

    Flask¶

    Name Purpose
    FlaskTenants(manager, app=None, strict_routes=False) The integration.
    tenant_required Decorator rejecting requests with no tenant.
    current_tenant_or_404() The active tenant, or abort(404).

    Binding and observability¶

    Name Purpose
    SchemaBinder The chokepoint. Constructed by TenantManager.
    warn_if_untracked(engine) Warn on autocommit statements with a tenant active. Development only.
    TenantLogFilter Adds tenant and tenant_schema to every log record.
    counters() {"no_tenant_attempts": int}.

    Schema naming¶

    Name Purpose
    derive_schema_name(id, prefix="tenant_") Build a name from a surrogate key.
    validate_schema_name(name, reserved_ok=False) Validate an identifier.
    validate_tenant_schema_name(name) Stricter: rejects public and the pg_ family.
    quote_identifier(name) Validate, then quote. Used on every interpolation.

    Exceptions¶

    All derive from TenantError.

    Exception Raised when
    NoActiveTenantError A tenant-scoped operation ran with no tenant active.
    UnknownTenantError A resolver produced a key with no matching tenant.
    TenantNotReadyError The tenant exists but is not servable, or a membership check failed.
    InvalidSchemaNameError A schema name failed validation.
    ProvisioningError Creating or migrating a tenant's schema failed.
    ModelLayoutError A shared table holds a foreign key into a tenant table.
    TenantLeakError A test observed another tenant's data.
